![wteam demo: `wteam tickets add`, live agent dashboard, `wteam run --pairs 2`, then commits](/wteam/demo.gif)

wteam turns a set of planned tickets into work done by pairs of agents. Each
worker implements one ticket. A reviewer checks the result against the ticket
and either passes it or sends it back. The orchestrator dispatches tickets and
the reviewer's verdicts decide what commits.

Agents talk through append-only mailboxes in `.wteam/`. The CLI works the same
for Claude Code, Codex, OpenCode, Pi and Cursor; see [Providers](./providers/)
for per-CLI setup. Permission profiles map differently per CLI —
[Permissions](./permissions/) and [Architecture](./architecture/).

The demo uses scripted stand-in agents so it is fast and repeatable; real runs
drive Claude Code, Codex, OpenCode or Pi. See [Benchmark](./benchmark/) for
measured runs with real models.
