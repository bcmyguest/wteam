wteam turns a set of planned tickets into work done by pairs of agents. Each
worker implements one ticket. A reviewer checks the result against the ticket
and either passes it or sends it back. The orchestrator dispatches tickets and
the reviewer's verdicts decide what commits.

Agents talk through append-only mailboxes in `.wteam/`. The CLI works the same
for Claude Code, Codex, opencode, pi and Cursor. Each CLI maps the permission
profiles differently; see [Permissions](./permissions/).

![wteam demo: `wteam tickets list`, live agent dashboard, `wteam run --pairs 2`, then commits](/wteam/demo.gif)

The demo uses scripted stand-in agents so it is fast and repeatable; real runs drive
Claude Code, Codex, opencode or pi. See [Benchmark](./benchmark/) for measured runs with real models.
